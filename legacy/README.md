# Archived build material

This directory preserves files from the earlier ThinkNode M9 build workflow. It is historical reference material and is not part of the active root build.

- `flake.nix` and `flake.lock` preserve the earlier Nix development shell.
- `patches/m9-unique_ptr-fix.patch` records a source fix used with an earlier firmware revision.

The active build recipe and current source overlays are maintained at the repository root.
